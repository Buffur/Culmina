# Culmina components

Use for composing, correcting or documenting existing Flutter controls and displays. Read [AGENTS](../../../AGENTS.md) and inspect the affected source/caller before choosing a component.

| Task | Reference | Preserve |
| --- | --- | --- |
| Field, action, choice, confirmation or deletion | [Forms](references/forms.md) | Units, validation, edited drafts and Save/Discard/Cancel |
| Context actions, detail template or destination | [Navigation](references/navigation.md) | Actual route adoption, Back/state and no-site semantics |
| Fit/state, disclosure, measurement or science graphic | [Data display](references/data-display.md) | Unknown, fit versus persistence/result state and source-owned calculations |

Read only the relevant group. Reuse the current component before adding an abstraction; inspect loading, missing-input, disabled, error and saved/changed states. Component availability or a gallery example does not prove production adoption.

For a changed contract, describe its purpose, inputs, states, interactions, semantics and real adopter. Preserve full labels, reachable actions, natural text growth and existing theme roles. A local component fix does not imply a routing redesign.

Report the source/caller, changed behavior, actual checks and limits. Native host renders, Android/device interaction and owner acceptance are separate evidence.
