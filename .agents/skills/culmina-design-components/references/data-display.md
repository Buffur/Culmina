# Data display: API and state map

Paths are relative to the repository root. Unqualified shared filenames are under `lib/presentation/shared/`; `widgets/` means `lib/presentation/widgets/`. Values come from existing domain/ViewModel contracts.

| API/source | Inputs, variants and slots | State and interaction contract | Adopter/check |
| --- | --- | --- | --- |
| `DocumentSection` in `document_section.dart` | Required existing `children`; optional padding (16 dp), joinPrevious/joinNext for lazy month slices | Flat surfaceSubtle, radius 8 dp, zero elevation. No new callback, clipping, semantic merging or fixed text height. Local Material preserves child ink/focus feedback. Keep source-owned chart/calendar widths and all existing actions | Tonight, Plan, Logbook, Night, Moon, Weather, Library, Settings, Record result; `test/presentation/shared/document_section_test.dart`; approved `docs/design/CONCEPT_B_IMPLEMENTATION_2026_10_24.md` |
| `SkyDarknessWidget` in `widgets/sky_darkness_widget.dart` | `embedded:false` keeps standalone framing; `embedded:true` uses the containing document group's frame/inset | Same remembered disclosure key, top sibling rule, Bortle/SQM/Unknown, independent provenance, picker and external-map action in both variants | Planner `home_screen.dart` uses embedded; `sky_darkness_context_test.dart` covers standalone facts and embedded control/persistence behavior; owner-approved U4-C, 2026-10-25 |
| `StatusBlock` in `lib/presentation/shared/status_block.dart` | Required `state:FitState`; optional `needed/usable:Duration?`, `reason`, `missing`, `keyNumbers:List<(String,String)>`, `action:Widget?` | Only show measured headline when both durations exist. Missing input uses its word, never fabricated zero. Action slot is caller-owned; the widget calculates nothing | `test/presentation/shared/status_block_test.dart`; Tonight instance; planner `plan_status.dart` uses `StatusBlock.headline` only; isolated trial |
| `PlanStateLabel(PlanState)` in `plan_state.dart` | States: notSaved, saved, savedChanged, tracking, completed, partly, notDone, oldLog. `PlanState.from` consumes status/savedBefore/legacy and optional resultKind | Persistence/result state is distinct from fit; do not infer “Saved” from “Fits”. Result states have existing icons. Current code supports partly; historical adoption text predates that implementation | Native gallery and `test/presentation/shared/plan_state_test.dart`; Logbook/planner |
| `CollapsibleSection` in `collapsible_section.dart` | Required sectionKey/title/child; optional summary/initiallyOpen; remembered form or controlled pair `open` **and** `onToggle` | Supply both controlled properties together; otherwise retain DisclosureViewModel. Closed child is not built. Summary remains visible; header has expanded semantics and 48 dp target. Reduced motion omits AnimatedSize | `test/presentation/shared/collapsible_section_test.dart`; isolated trial |
| `ChangeMark` in `change_mark.dart` | Required value and child; value change triggers the existing transient cue | Does not persist or compute domain state. Preserve the original value/change boundary and reduced-motion behavior | `test/presentation/widgets/capture_outputs_test.dart` and actual planner callers |
| `AltitudeChartWidget` in `widgets/altitude_chart_widget.dart` | Required opportunity; optional moonAltitudesDeg, zoneId, nowUtc, captureEndUtc; `TimelineDensity.full/compact` | Full has grid/legend; compact retains timing information. Existing painter/timeline data owns scientific geometry. Use chart tokens, not approximate CSS astronomy | `test/presentation/design_system/u_renders_test.dart`; `widgets/tonight_opportunity_widget.dart` contains a call, but that wrapper has no production instantiation at this snapshot; current night-browser timeline is separate |
| `StackingGainGraph` in `widgets/capture_plan/stacking_gain_graph.dart` | Required curve and groupLabel; optional caption and recorded frame count | Graph is relative improvement over integration time normalized to the plan (1.00×), with plan/comparison and optional recorded marks. Preserve the existing curve and per-group exposure/filter meaning; no absolute SNR or universal score. Hybrid functional gradients are presentation, not new science | `widgets/capture_plan/capture_budget_summary.dart`; existing graph/curve checks and planner |
| `NightBarSection` in `widgets/night_browser_sections.dart` | Existing browser ViewModel/site providers; `compact`, `home` presentation flags | Two exact-boundary jump actions, 16 dp before the 48 dp slider region. Current instant/state stays visible. Legend, encoding warning and exact intervals are behind the initially closed `Exact times & reading key` action; opening it changes no preview/plan data. Preserve sky/Moon lanes and five-minute browse semantics | Tonight and Night & Moon detail; `night_moon_browse_test.dart`, scoped physical checks and real-font renders in the 2026-10-24 Home layout report |

Use `NightTimeFormatter` / `QuantityText` and the existing word helpers for dates, units and labels. For every touched component record the needed variant, state, slots, input provenance and relevant check; do not analyse every category for an unrelated change.
