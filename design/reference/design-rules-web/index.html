Action and input rules

  • Primary, outlined, text and disabled actions keep their names and minimum 48 px targets.
  • Labels reflow; content has natural height. Large text uses two navigation items per row, as the native shell does from 150%.
  • Leaving changed work opens Save / Discard / Cancel. Dismissal preserves the draft; a simulated save failure keeps it open.
  • Validation names the problem and recovery; color is supplemental.
  • Site / night / target / rig selection and final Save plan are distinct steps.
