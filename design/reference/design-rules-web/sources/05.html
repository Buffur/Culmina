6 # Culmina spacing, shape and motion
7
8 Use for local spacing, alignment, density, radius, border and functional-motion work. Read [AGENTS](../../../AGENTS.md), the affected widget/callers and the relevant definitions in `lib/core/theme/app_spacing.dart`, `app_radius.dart` and `app_motion.dart`.
9
10 - Distinguish scale values, component padding and screen gutters. `md=16`, `gutter=20` and `section=28` are available values, not instructions to normalize every screen.
11 - Inspect actual screen padding and chart/calendar width constraints before adjusting a gap. `DocumentSection` in `lib/presentation/shared/document_section.dart` supplies flat grouping, default 16 dp padding and 8 dp corners; preserve child actions, focus and natural text height.
12 - Improve grouping before shrinking text. Diagnose width/height and scrolling ownership before adding flex or wrapping; use [layout diagnosis](../flutter-fix-layout-issues/SKILL.md) for an actual constraint error.
13 - Preserve reachable controls, full labels, text scaling and large-content scrolling. Avoid clipping, fixed text-card heights or a smaller user scaler as overflow repairs.
14 - Read shape values from AppRadius: small 6, menu 8, large 12, pill 999. Inspect the caller's current role before changing it.
15 - Use AppMotion and its reduced-motion handling. Source-owned scientific sky ramps and stacking-gain gradients are functional data presentation, not permission to add decorative effects.
16
17 A phone overflow does not call for new navigation or an adaptive shell. Use the named adaptive-layout skill only for that task.
18
19 Report the geometry/source/caller, chosen correction, actual checks and limits. A static render establishes only its captured theme, size, scale and state.
