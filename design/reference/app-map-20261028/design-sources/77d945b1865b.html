   1  # Form elements: API and state map
   2  
   3  Paths below are relative to the repository root. Unqualified shared filenames are under `lib/presentation/shared/`; `app_button_styles.dart` is under `lib/core/theme/`. Inspect the named API before editing; this index routes to source and does not replace it.

  14  For selection: radio/segments express one of a few mutually exclusive values; searchable select expresses a larger single-choice set; checkboxes express independent selections; switches apply a binary setting. An option count does not change the underlying choice semantics. Error text must name the problem and recovery; colour is additional information.
