   6  # Code Connect Components
   7  
   8  ## Overview
   9  
  10  This skill helps you connect Figma design components to their corresponding code implementations using Figma's Code Connect feature. It analyzes the Figma design structure, searches your codebase for matching components, and establishes mappings that maintain design-code consistency.
  11  
  12  ## Skill Boundaries
  13  
  14  - Use this skill for `get_code_connect_suggestions` + `send_code_connect_mappings` workflows.
  15  - If the task requires writing to the Figma canvas with Plugin API scripts, switch to [figma-use](../figma-use/SKILL.md).
  16  - If the task is building or updating a full-page screen in Figma from code or a description, switch to [figma-generate-design](../figma-generate-design/SKILL.md).
  17  - If the task is implementing product code from Figma, switch to [figma-implement-design](../figma-implement-design/SKILL.md).
  18  
  19  ## Prerequisites
  20  
  21  - Figma MCP server must be connected and accessible
  22  - User must provide a Figma URL with node ID: `https://figma.com/design/:fileKey/:fileName?node-id=1-2`
  23    - **IMPORTANT:** The Figma URL must include the `node-id` parameter. Code Connect mapping will fail without it.
  24  - **OR** when using `figma-desktop` MCP: User can select a node directly in the Figma desktop app (no URL required)
  25  - **IMPORTANT:** The Figma component must be published to a team library. Code Connect only works with published components or component sets.
  26  - **IMPORTANT:** Code Connect is only available on Organization and Enterprise plans.
  27  - Access to the project codebase for component scanning
  28  
  29  ## Required Workflow
  30  
  31  **Follow these steps in order. Do not skip steps.**
  32  
  33  ### Step 1: Get Code Connect Suggestions
  34  
  35  Call `get_code_connect_suggestions` to identify all unmapped components in a single operation. This tool automatically:
  36  
  37  - Fetches component info from the Figma scenegraph
  38  - Identifies published components in the selection
  39  - Checks existing Code Connect mappings and filters out already-connected components
  40  - Returns component names, properties, and thumbnail images for each unmapped component
  41  
  42  #### Option A: Using `figma-desktop` MCP (no URL provided)
  43  
  44  If the `figma-desktop` MCP server is connected and the user has NOT provided a Figma URL, immediately call `get_code_connect_suggestions`. No URL parsing is needed — the desktop MCP server automatically uses the currently selected node from the open Figma file.
  45  
  46  **Note:** The user must have the Figma desktop app open with a node selected. `fileKey` is not passed as a parameter — the server uses the currently open file.
  47  
  48  #### Option B: When a Figma URL is provided
  49  
  50  Parse the URL to extract `fileKey` and `nodeId`, then call `get_code_connect_suggestions`.
  51  
  52  **IMPORTANT:** When extracting the node ID from a Figma URL, convert the format:
  53  
  54  - URL format uses hyphens: `node-id=1-2`
  55  - Tool expects colons: `nodeId=1:2`
  56  
  57  **Parse the Figma URL:**
  58  
  59  - URL format: `https://figma.com/design/:fileKey/:fileName?node-id=1-2`
  60  - Extract file key: `:fileKey` (segment after `/design/`)
  61  - Extract node ID: `1-2` from URL, then convert to `1:2` for the tool
  62  
  63  ```
  64  get_code_connect_suggestions(fileKey=":fileKey", nodeId="1:2")
  65  ```
  66  
  67  **Handle the response:**
  68  
  69  - If the tool returns **"No published components found in this selection"** → inform the user and stop. The components may need to be published to a team library first.
  70  - If the tool returns **"All component instances in this selection are already connected to code via Code Connect"** → inform the user that everything is already mapped.
  71  - Otherwise, the response contains a list of unmapped components, each with:
  72    - Component name
  73    - Node ID
  74    - Component properties (JSON with prop names and values)
  75    - A thumbnail image of the component (for visual inspection)
  76  
  77  ### Step 2: Scan Codebase for Matching Components
  78  
  79  For each unmapped component returned by `get_code_connect_suggestions`, search the codebase for a matching code component.
  80  
  81  **What to look for:**
  82  
  83  - Component names that match or are similar to the Figma component name
  84  - Component structure that aligns with the Figma hierarchy
  85  - Props that correspond to Figma properties (variants, text, styles)
  86  - Files in typical component directories (`src/components/`, `components/`, `ui/`, etc.)
  87  
  88  **Search strategy:**
  89  
  90  1. Search for component files with matching names
  91  2. Read candidate files to check structure and props
  92  3. Compare the code component's props with the Figma component properties returned in Step 1
  93  4. Detect the programming language (TypeScript, JavaScript) and framework (React, Vue, etc.)
  94  5. Identify the best match based on structural similarity, weighing:
  95     - Prop names and their correspondence to Figma properties
  96     - Default values that match Figma defaults
  97     - CSS classes or style objects
  98     - Descriptive comments that clarify intent
  99  6. If multiple candidates are equally good, pick the one with the closest prop-interface match and document your reasoning in a 1-2 sentence comment before your tool call
 100  
 101  **Example search patterns:**
 102  
 103  - If Figma component is "PrimaryButton", search for `Button.tsx`, `PrimaryButton.tsx`, `Button.jsx`
 104  - Check common component paths: `src/components/`, `app/components/`, `lib/ui/`
 105  - Look for variant props like `variant`, `size`, `color` that match Figma variants
 106  
 107  ### Step 3: Present Matches to User
 108  
 109  Present your findings and let the user choose which mappings to create. The user can accept all, some, or none of the suggested mappings.
 110  
 111  **Present matches in this format:**
 112  
 113  ```
 114  The following components match the design:
 115  - [ComponentName](path/to/component): DesignComponentName at nodeId [nodeId](figmaUrl?node-id=X-Y)
 116  - [AnotherComponent](path/to/another): AnotherDesign at nodeId [nodeId2](figmaUrl?node-id=X-Y)
 117  
 118  Would you like to connect these components? You can accept all, select specific ones, or skip.
 119  ```
 120  
 121  **If no exact match is found for a component:**
 122  
 123  - Show the 2 closest candidates
 124  - Explain the differences
 125  - Ask the user to confirm which component to use or provide the correct path
 126  
 127  **If the user declines all mappings**, inform them and stop. No further tool calls are needed.
 128  
 129  ### Step 4: Create Code Connect Mappings
 130  
 131  Once the user confirms their selections, call `send_code_connect_mappings` with only the accepted mappings. This tool handles batch creation of all mappings in a single call.
 132  
 133  **Example:**
 134  
 135  ```
 136  send_code_connect_mappings(
 137    fileKey=":fileKey",
 138    nodeId="1:2",
 139    mappings=[
 140      { nodeId: "1:2", componentName: "Button", source: "src/components/Button.tsx", label: "React" },
 141      { nodeId: "1:5", componentName: "Card", source: "src/components/Card.tsx", label: "React" }
 142    ]
 143  )
 144  ```
 145  
 146  **Key parameters for each mapping:**
 147  
 148  - `nodeId`: The Figma node ID (with colon format: `1:2`)
 149  - `componentName`: Name of the component to connect (e.g., "Button", "Card")
 150  - `source`: Path to the code component file (relative to project root)
 151  - `label`: The framework or language label for this Code Connect mapping. Valid values include:
 152    - Web: 'React', 'Web Components', 'Vue', 'Svelte', 'Storybook', 'Javascript'
 153    - iOS: 'Swift UIKit', 'Objective-C UIKit', 'SwiftUI'
 154    - Android: 'Compose', 'Java', 'Kotlin', 'Android XML Layout'
 155    - Cross-platform: 'Flutter'
 156    - Docs: 'Markdown'
 157  
 158  **After the call:**
 159  
 160  - On success: the tool confirms the mappings were created
 161  - On error: the tool reports which specific mappings failed and why (e.g., "Component is already mapped to code", "Published component not found", "Insufficient permissions")
 162  
 163  **Provide a summary** after processing:
 164  
 165  ```
 166  Code Connect Summary:
 167  - Successfully connected: 3
 168    - Button (1:2) → src/components/Button.tsx
 169    - Card (1:5) → src/components/Card.tsx
 170    - Input (1:8) → src/components/Input.tsx
 171  - Could not connect: 1
 172    - CustomWidget (1:10) - No matching component found in codebase
 173  ```

 252  ## Best Practices
 253  
 254  ### Proactive Component Discovery
 255  
 256  Don't just ask the user for the file path — actively search their codebase to find matching components. This provides a better experience and catches potential mapping opportunities.
 257  
 258  ### Accurate Structure Matching
 259  
 260  When comparing Figma components to code components, look beyond just names. Check that:
 261  
 262  - Props align (variant types, size options, etc.)
 263  - Component hierarchy matches (nested elements)
 264  - The component serves the same purpose
 265  
 266  ### Clear Communication
 267  
 268  When offering to create a mapping, clearly explain:
 269  
 270  - What you found
 271  - Why it's a good match
 272  - What the mapping will do
 273  - How props will be connected
 274  
 275  ### Handle Ambiguity
 276  
 277  If multiple components could match, present options rather than guessing. Let the user make the final decision about which component to connect.
 278  
 279  ### Graceful Degradation
 280  
 281  If you can't find an exact match, provide helpful next steps:
 282  
 283  - Show close candidates
 284  - Suggest component creation
 285  - Ask for user guidance

 287  ## Common Issues and Solutions
 288  
 289  ### Issue: "No published components found in this selection"
 290  
 291  **Cause:** The Figma component is not published to a team library. Code Connect only works with published components.
 292  **Solution:** The user needs to publish the component to a team library in Figma:
 293  
 294  1. In Figma, select the component or component set
 295  2. Right-click and choose "Publish to library" or use the Team Library publish modal
 296  3. Publish the component
 297  4. Once published, retry the Code Connect mapping with the same node ID
 298  
 299  ### Issue: "Code Connect is only available on Organization and Enterprise plans"
 300  
 301  **Cause:** The user's Figma plan does not include Code Connect access.
 302  **Solution:** The user needs to upgrade to an Organization or Enterprise plan, or contact their administrator.
 303  
 304  ### Issue: No matching component found in codebase
 305  
 306  **Cause:** The codebase search did not find a component with a matching name or structure.
 307  **Solution:** Ask the user if the component exists under a different name or in a different location. They may need to create the component first, or it might be located in an unexpected directory.
 308  
 309  ### Issue: "Published component not found" (CODE_CONNECT_ASSET_NOT_FOUND)
 310  
 311  **Cause:** The source file path is incorrect, the component doesn't exist at that location, or the componentName doesn't match the actual export.
 312  **Solution:** Verify the source path is correct and relative to the project root. Check that the component is properly exported from the file with the exact componentName specified.
 313  
 314  ### Issue: "Component is already mapped to code" (CODE_CONNECT_MAPPING_ALREADY_EXISTS)
 315  
 316  **Cause:** A Code Connect mapping already exists for this component.
 317  **Solution:** The component is already connected. If the user wants to update the mapping, they may need to remove the existing one first in Figma.
 318  
 319  ### Issue: "Insufficient permissions to create mapping" (CODE_CONNECT_INSUFFICIENT_PERMISSIONS)
 320  
 321  **Cause:** The user does not have edit permissions on the Figma file or library.
 322  **Solution:** The user needs edit access to the file containing the component. Contact the file owner or team admin.
 323  
 324  ### Issue: Code Connect mapping fails with URL errors
 325  
 326  **Cause:** The Figma URL format is incorrect or missing the `node-id` parameter.
 327  **Solution:** Verify the URL follows the required format: `https://figma.com/design/:fileKey/:fileName?node-id=1-2`. The `node-id` parameter is required. Also ensure you convert `1-2` to `1:2` when calling tools.
 328  
 329  ### Issue: Multiple similar components found
 330  
 331  **Cause:** The codebase contains multiple components that could match the Figma component.
 332  **Solution:** Present all candidates to the user with their file paths and let them choose which one to connect. Different components might be used in different contexts (e.g., `Button.tsx` vs `LinkButton.tsx`).
 333  
 334  ## Understanding Code Connect
 335  
 336  Code Connect establishes a bidirectional link between design and code:
 337  
 338  **For designers:** See which code component implements a Figma component
 339  **For developers:** Navigate from Figma designs directly to the code that implements them
 340  **For teams:** Maintain a single source of truth for component mappings
 341  
 342  The mapping you create helps keep design and code in sync by making these connections explicit and discoverable.
