   6  # Gather identity assets for a document
   7  
   8  Start by obtaining the organization's existing website identity when the document requires assets not already supplied. Discover the scrape tool and live schema from the Firecrawl MCP.
   9  
  10  - With a supplied domain, scrape the homepage first. When supported, request `formats: ["branding", "markdown"]` to obtain palette, typography and logo candidates alongside the exact homepage messaging. Search through the Firecrawl MCP only when the official domain is missing or unresolved.
  11  - Assemble a compact asset reference: logo asset URLs and available variants; observed primary/background/text/accent colors with hex values; heading and body fonts with available weights; exact homepage headline and any explicit tagline.   12  - If a needed logo variant or official download is absent, follow an observed link to the organization's brand-assets page. Do not repeat retrieval when the necessary evidence is already available.

  14  - Report the existing identity. Do not create a strategy, infer sentiment or manufacture missing assets. Respect no-browse requests and use supplied assets when adequate. Follow live tool arguments rather than inventing a schema.
