   6  # create_new_file — Create a New Figma File
   7  
   8  Use the `create_new_file` MCP tool to create a new blank Figma file in the user's drafts folder. This is typically used before `use_figma` when you need a fresh file to work with.
   9  
  10  ## Skill Arguments
  11  
  12  This skill accepts optional arguments: `/figma-create-new-file [editorType] [fileName]`
  13  
  14  - **editorType**: `design` (default) or `figjam`
  15  - **fileName**: Name for the new file (defaults to "Untitled")
  16  
  17  Examples:
  18  - `/figma-create-new-file` — creates a design file named "Untitled"
  19  - `/figma-create-new-file figjam My Whiteboard` — creates a FigJam file named "My Whiteboard"
  20  - `/figma-create-new-file design My New Design` — creates a design file named "My New Design"
  21  
  22  Parse the arguments from the skill invocation. If editorType is not provided, default to `"design"`. If fileName is not provided, default to `"Untitled"`.
  23  
  24  ## Workflow
  25  
  26  ### Step 1: Resolve the planKey
  27  
  28  The `create_new_file` tool requires a `planKey` parameter. Follow this decision tree:
  29  
  30  1. **User already provided a planKey** (e.g. from a previous `whoami` call or in their prompt) → use it directly, skip to Step 2.
  31  
  32  2. **No planKey available** → call the `whoami` tool. The response contains a `plans` array. Each plan has a `key`, `name`, `seat`, and `tier`.
  33  
  34     - **Single plan**: use its `key` field automatically.
  35     - **Multiple plans**: ask the user which team or organization they want to create the file in, then use the corresponding plan's `key`.
  36  
  37  ### Step 2: Call create_new_file
  38  
  39  Call the `create_new_file` tool with:
  40  
  41  | Parameter    | Required | Description |
  42  |-------------|----------|-------------|
  43  | `planKey`   | Yes      | The plan key from Step 1 |
  44  | `fileName`  | Yes      | Name for the new file |
  45  | `editorType`| Yes      | `"design"` or `"figjam"` |
  46  
  47  Example:
  48  ```json
  49  {
  50    "planKey": "team:123456",
  51    "fileName": "My New Design",
  52    "editorType": "design"
  53  }
  54  ```
  55  
  56  ### Step 3: Use the result
  57  
  58  The tool returns:
  59  - `file_key` — the key of the newly created file
  60  - `file_url` — a direct URL to open the file in Figma
  61  
  62  Use the `file_key` for subsequent tool calls like `use_figma`.
  63  
  64  ## Important Notes
  65  
  66  - The file is created in the user's **drafts folder** for the selected plan.
  67  - Only `"design"` and `"figjam"` editor types are supported.
  68  - If `use_figma` is your next step, load the `figma-use` skill before calling it.
