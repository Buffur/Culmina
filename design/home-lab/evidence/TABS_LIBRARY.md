# Library module — 2026-10-20

Current Hybrid behaviour is documented in [the subsequent implementation and QA](../../../docs/design/HYBRID_IMPLEMENTATION_2026_10_20.md). This dated record describes the earlier tabs baseline; its separate-Plan/backup limitations are superseded where explicitly implemented there.

Scope: the existing Android browser prototype, Hybrid Notion + Journal. `library.js` exports `mountLibrary(root, api)`; `library.css` scopes its styles to `.library-view`. The CLI worker supplied JavaScript but hit a session limit before styles/report; the parent completed styling, repaired focus handling, integrated and tested it. The partial worker is not counted as completed implementation.

Functional sources inspected by the worker are recorded individually in [its result summary](tabs-2026-10-20/claude-library-result.json): `LibraryScreen`, `EquipmentSelectionScreen`, equipment editor/Add rig panel, `equipment_form_input.dart`, `rig_input_text.dart`, `EquipmentLimits`, camera/tracking classes, TargetSelectionScreen/target input and RA/Dec parsing, SitesScreen/SiteEditorScreen and coordinate/site validators. The parent also compared all six copied catalogue records against `assets/catalog/catalog_v2.json`.

Implemented: root Rigs/Targets/Sites; stable per-list search; record details; inline Add/Edit with Save/Cancel and dirty guard; actual class-dependent rig fields, resolution/pixel-derived sensor dimensions and focal length/aperture consistency; target J2000 RA/Dec parsing and optional size/magnitude; site bounds, IANA zone and optional elevation/Bortle/SQM with provenance; confirmation before delete and identifier-safe Undo. The catalogue sample is read-only and explicitly 6 of 164. Missing equipment properties say Not recorded. Library edits do not activate a site or change a plan/snapshot.

Only storage key: `culmina-library-preview-v1`, envelope `{kind, version, rigs, targets, sites}`. Invalid envelopes stay unchanged; memory-only presentation is labelled. Fresh reads before mutations retain unrelated concurrent records; edits detect a changed record. Empty/error/storage-error scenarios are explicit. No production database, GPS, maps, online lookup or metadata file parser is connected.

Executed parent browser checks include alias search, catalogue read-only details, invalid/valid RA/Dec, custom target Add/Edit/Delete/Undo, invalid latitude, valid site/zone and reload, rig unknowns, editor Cancel and a new DSLR rig (6000 × 4000 px, 4 µm → 24 × 16 mm sensor; 135 mm optics), failed Save/Retry, malformed/denied storage and unchanged plan/checkpoint keys. Lists, details and all three editors were measured at 200% in light/dark/field. [Integrated evidence](TABS_PREVIEW.md) contains exact counts, scripts and limitations.
