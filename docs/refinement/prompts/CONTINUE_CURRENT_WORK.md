# Prompt — Continue current work

Use [AGENTS](../../../AGENTS.md), [AI_WORKFLOW](../../AI_WORKFLOW.md) and [VERIFICATION_POLICY](../../VERIFICATION_POLICY.md) as canonical rules. This template supplies no independent task or Git permission.

1. Perform AI_WORKFLOW preflight. Read [PROGRESS](../PROGRESS.md), then identify the next action that fits the current owner's request.
2. Read only that action's approved contract, decision/finding IDs and affected source/tests. F/G criteria live in FINAL_COMPLETION_ROADMAP; older S aliases resolve through POST_ROADMAP_PLAN. These are contracts, not an active queue.
3. Execute the authorized task under AI_WORKFLOW and V1–V8. For an explicitly launched finite group, continue dependency-ready tasks only within that group's named boundary; record unavailable items under V7.
4. For research or owner decisions, prepare the requested evidence/decision. For validation, use [INDEPENDENT_STAGE_VALIDATION](INDEPENDENT_STAGE_VALIDATION.md).
5. Update PROGRESS using AI_WORKFLOW's handoff requirements; preserve superseded receipts in PROGRESS_HISTORY. Commit/deliver only with the current owner's authorization, then stop at the task boundary.

Completed full-plan launch prompts are historical evidence in the [archive index](../../archive/2026-10-27_cleanup/ARCHIVE_INDEX.md); their permissions and next steps cannot activate another run.
