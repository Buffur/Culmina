### R2 — P2, F06 A5: a fraction can throw instead of showing a field error

[ExposureInput.parse](../../lib/domain/services/exposure_input.dart) uses `int.parse` for both fraction components. `ExposureInput.problem('18446744073709551616/1')` and `problem('1/18446744073709551616')` throw `FormatException: Positive input exceeds the limit of integer`. The block form calls this method directly as its validator. Normal `1/14`, decimal, zero-denominator and class hierarchy tests pass, but out-of-range pasted fraction text escapes field validation. Use bounded/fallible parsing and preserve canonical seconds and existing domain bounds. Both independent failures are in the probe log/patch above; no product fix was made.

### R3 — P2, F10 A2/A3 and science invariant: real FITS conversion gain is proposed as acquisition gain

The public `astropy/ccdproc` telescope fixture `a8280271.fits` is 561,600 bytes, has real telescope/instrument header identities, two axes 536×520, BITPIX 16 and EXPTIME 150.040. Its actual card is **`GAIN = 1.9 / e-/ADU`**. The repository distributes this data with its BSD-3-Clause source package; the data README declares no separate exception. Immutable commit, hash and source/license links are in [provenance](evidence/finalization/develop_review_20261019/fits_provenance.json). This is a public telescope test image, not an owner's camera sub-frame or proof of all amateur writer conventions.

[FitsMetadataReader](../../lib/domain/metadata/fits_metadata_reader.dart) discards the card comment and always maps GAIN to `acquisitionGain`; [BlockProposal](../../lib/domain/services/block_proposal.dart) consequently proposes driver gain **1.9** for an astro rig. The reader/proposal/measured-size test passes, while the independent no-unit-conflation assertion fails. C21's keyword mapping is implemented literally, but its assumption does not safely cover this real writer. This is new contradictory scientific evidence, not permission to rewrite the accepted ADR: preserve raw provenance, classify unsupported/explicit conversion semantics safely, and record any necessary bounded ADR clarification before extending the writer contract. A full real FITS rig/block/cancel/phone qualification is still missing; synthetic N.I.N.A.-style fixtures cannot replace it.
