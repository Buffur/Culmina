# Hybrid: перевірка за дев’ятьма фото — 2026-10-20

**Висновок: основні зміни за фото підтверджені; V3/V5 виконані частково.** У виборі Focus mode при 200% слово `Unrecorded` розривається всередині слова. Це відтворюється при 360 і 412 px у light/dark/field. Загальне твердження про повне завершення потребує цього уточнення.

Перевірено браузерний Hybrid `blend`, ревізію `20261020-hybrid7`, відповідно до попереднього завдання R1–R8, V1–V10, F1–F2. Дев’ять наданих тепер фотографій використано як візуальні референси проблем із того завдання. Написи на зображеннях не трактувалися як нові інструкції. Це адресна перевірка виконання; код застосунку в цьому проході не змінено.

## RV-01 — довгий підпис Focus mode при 200% [P2]

- Кроки: відкрити Plan → Edit першого Light block → Focus mode, увімкнути 200% тексту.
- Факт: усі **6 із 6** enlarged-комбінацій (360/412 px × три теми) розривають `Unrecorded` на два рядки всередині слова. Усі 6 нормальних комбінацій відображають слово одним рядком. Виміряні рядки самого текстового вузла, а не лише загальна геометрія контейнера.
- Причина: `plan.css:62` задає `.segmented .choice` `flex-basis:40%` при 200%; `.choice-text` має `min-width:0` і успадковує можливість довільного розриву. Відсутність горизонтального overflow не доводить читабельність напису.
- Потрібна корекція: дати довгій опції достатню ширину або скласти focus options в одну колонку при 200%. Зберегти поточний розмір тексту, область натискання та radio/keyboard поведінку. Числова MF-шкала до цього дефекту не стосується.
- Статус: **відкрито; в цьому перевірочному проході не виправлялося**.

Докази: [поточний dark/200% crop](../../design/home-lab/evidence/hybrid-reference-verification-2026-10-20/current/09-dark-2.png), [12 вимірювань підпису](../../design/home-lab/evidence/hybrid-reference-verification-2026-10-20/focus-labels.json). Native контракт `lib/domain/models/capture_evidence.dart:132–137` прямо визначає AF/MF як описовий запис, без числового значення, команди чи inference з файла; Hybrid `plan.js:685–686` зберігає чесне пояснення.
