# Hybrid: доопрацювання і повторний QA — 2026-10-20

Поточна реалізація — Android-форматний браузерний прототип `design/home-lab/`, HTML/CSS/JavaScript без збірника. Варіант: **`blend`**, ревізія **`20261020-hybrid7`**. Зміни стосуються наявних можливостей Hybrid. Flutter-код використано для перевірки продуктового змісту; native adoption не виконувалося.

Підстава: [завдання продовження](HYBRID_CONTINUATION_2026_10_20.md), [попередня оцінка](HYBRID_FULL_REASSESSMENT_2026_10_20.md) і нове завдання власника R1–R8, V1–V10, F1–F2. Нове завдання обирає узгодження початкових припущень із Settings і дозволяє реалізацію. Старе відкрите питання R1 більше не блокує роботу. Під час первинного проходу зображення (2)–(10) були недоступні. Після отримання дев’яти фото виконано [адресне зіставлення з референсами](HYBRID_REFERENCE_VERIFICATION_2026_10_20.md): основні зміни підтверджені, але **V3/V5 частково виконані через розрив Unrecorded при 200% (RV-01)**. Код застосунку в цьому додатковому проході не змінено. Наведені нижче тести й Claude QA є результатами попереднього проходу; вони не закривають цю нововиявлену проблему.

## Відповідність функціоналу

Матриця **функція → підтвердження → Hybrid → розбіжність → дія** з реальними native шляхами: [DATA_CONTRACTS.md](../../../../../../design/home-lab/evidence/hybrid-refinement-2026-10-20/DATA_CONTRACTS.md). Вона охоплює Tonight/candidates, Plan/editors, Night/Moon, Weather, Logbook/results/Progress, Library, Settings/backup і Welcome.

Детальний F1: [LIBRARY_IMPORT.md](../../../../../../design/home-lab/evidence/hybrid-refinement-2026-10-20/LIBRARY_IMPORT.md). Native підтримує DNG / JPEG / HEIC/HEIF still / FITS; інші RAW можуть розпізнаватися як непідтримувані. Rig-import пропонує equipment facts, Light-block import — exposure, ISO або gain, WB та доречні FITS filter/binning. Кількість кадрів і фокус не вгадуються. Native saved-rig matching / конфлікти не перенесено як достовірний браузерний розрахунок. JSON значень rig та JSON backup / restore — окремі наявні потоки, не photo metadata.

Plan імпорт зберігає явний provenance прикладу; ручна зміна поля прибирає його file-source label. Apply у metadata-review змінює лише редактор; Apply changes — plan draft; Save plan — збережений запис. Відсутні / unchecked поля не перезаписуються.

## Перевірки і докази

Фінальні результати: **84/84 модельні тести**, **11/11 ізольованих сценаріїв Library / Plan provenance**, **31/31 адресна перевірка Night/Moon/Weather**, **137/137 базових зведених браузерних перевірок** та **51/51 фінальна корекційна перевірка**. JavaScript syntax checks пройшли для всіх frontend `.js`; збірника / окремого lint-конфігуратора цей static lab не має. `git diff --check` пройшов. Impeccable detector повернув порожній список; це лише механічна перевірка, не доказ виконання продуктових критеріїв.

Точне фінальне покриття — [BROWSER_QA_FINAL.md](../../../../../../design/home-lab/evidence/hybrid-refinement-2026-10-20/BROWSER_QA_FINAL.md) та [browser-final-checks.json](../../../../../../design/home-lab/evidence/hybrid-refinement-2026-10-20/browser-final-checks.json): усі вісім roots × 412 px × light/dark/field × 100/200% (48 комбінацій), плюс усі вісім при 360 px/light/200% (ще 8). Перевірено шість Plan editors у трьох темах при 200%, дочірні Library/Settings/Logbook, import / restore, доречні empty/error/partial/no-site/DST стани, keyboard/reset та reduced motion усіх восьми roots. Після корекцій є 64 різні root-комбінації та 178 поточних / незачеплених повторно використаних записів screenshot-manifest. 15 старих affected скриншотів позначено історичними. Первинні 207 сирих скриншотів зведених запусків і нові 53 корекційні (+ 4 порівняння галереї) збережено. Ці числа не є кількістю вимог чи оцінкою якості.

Не виявлено непередбаченого горизонтального overflow або видимих target boxes менших за 48 px (допуск округлення 0,5 px; для radio/checkbox вимірюється натискна label-область). Горизонтальні погодинні / табличні scrollers є навмисними. Фінальні адресні запуски мають стабільні хеші джерел і 0 помилок сторінки / консолі / ресурсів. Початкові 8 різних збоїв стенда / тимчасового доступу до preview збережено й явно заміщено успішними адресними результатами. Виправлено реальні Home360/200 overflow і застаріле metadata-позначення після ручного ISO.

Команди відтворення: `node --test design/home-lab/scripts/check_hybrid_defaults.mjs design/home-lab/scripts/check_bridge.mjs design/home-lab/scripts/check_plan.mjs design/home-lab/scripts/check_night.mjs design/home-lab/scripts/check_quality.mjs`; `node design/home-lab/scripts/check_hybrid_library_refinement.cjs`; `node design/home-lab/scripts/check_hybrid_refinement.cjs`. Корекційний прогін: `node design/home-lab/scripts/check_hybrid_corrections.cjs`. Для зведеного стенда потрібен чинний loopback preview на 4173 і вже встановлений pinned Playwright 1.64.1 / Chromium 1248. Нових залежностей застосунку не додано.

Незалежний Claude CLI QA **фактично завершився**, exit 0, `success`, без permission denials: CLI 2.1.304, модель `claude-opus-5-5`, 87 turns, приблизно 7 хв 35 с. [Оригінальний JSON](../../../../../../design/home-lab/evidence/hybrid-refinement-2026-10-20/claude-qa-original.json), [читабельний результат](../../../../../../design/home-lab/evidence/hybrid-refinement-2026-10-20/CLAUDE_QA.md), [prompt](../../../../../../design/home-lab/evidence/hybrid-refinement-2026-10-20/CLAUDE_QA_PROMPT.txt), [команда](../../../../../../design/home-lab/evidence/hybrid-refinement-2026-10-20/CLAUDE_QA_COMMAND.txt) збережені без переписування. Claude сам прочитав 36 PNG (31 вибраний + 5 додаткових), адресний код і документи; браузером не керував, взаємодії підтверджували батьківські тести.

Первинний результат Claude — **30/40, fixes required**. Це оцінка до пакета виправлень, не фінальна переоцінка після нього. Вона має інше покриття, ніж історичні 33/40 / 31/40: її не подано як вимір погіршення чи покращення usability.
