## Conversion and status definitions

- `used`: current native adopter inspected; named host checks establish token/form behavior. Per-screen/native acceptance remains separate in Matrix A.
- `transformed`: source value deliberately converted/overridden with an explicit reason; actual adopter and evidence are identified.
- `not applicable`: explicit reason excludes this scalar from runtime configuration (metadata, alternate variants, historical snapshot-only token or preview well).
- `blocked`: reserved for a required scalar with no current implementation. No JSON leaf is blocked at this checkpoint; this does not close remaining CSS/UI/native obligations.

Hex `#RRGGBB` is opaque sRGB: Flutter integer form `0xFFRRGGBB`; do not swap alpha to the trailing CSS position. No JSON colors contain alpha. CSS dimensions become logical pixels; typography px becomes the same logical font size at 100%, multiplied once by platform text scaling. Unitless line height from CSS becomes `TextStyle.height`; `.02em` letter spacing becomes fontSize × .02. Durations parse explicit `ms`, not seconds. CSS cubic arguments map in order to Cubic(x1,y1,x2,y2). The 999 pill radius means a capsule clipped by available geometry, not an enormous layout dimension.
