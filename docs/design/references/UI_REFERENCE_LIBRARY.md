## A. Systemic diagnosis

The foundation is coherent: Geist roles, 20 dp page sides, semantic tonal groups, staged Plan actions and immediate settings are already implemented. A global font, palette or navigation replacement is unsupported by the evidence. The recurring problems arise at **composition and state boundaries**:

1. **A shared primitive cannot choose its caller's grouping.** `DocumentSection` contributes 16 dp content padding; `CollapsibleSection` defaults to a leading rule; rows own terminal rules; legacy `SkyDarknessWidget` contributes another Card/padding. Nesting these unchanged produces extra boundaries and insets. Current Site detail demonstrates the restrained alternative using the existing flags.
2. **Some conditional and asynchronous states escape settled-render coverage.** Results retains two 16 dp gaps when its conditional middle group disappears. Target aliases maps both pending and failed reads to an empty list. A cached Home forecast does not disclose the refresh failure shown by Weather detail. These need explicit state composition, not cosmetic token changes.
3. **Exception-free rendering is weaker than visual acceptance.** Weather's `km/h` breaks into `km/` plus an orphan `h` at 375 dp/100%, while `layoutError` is null. Component growth/tap-target tests do not judge unit integrity, unnecessary rules or caller alignment.
4. **Fixtures must preserve domain invariants as they evolve.** Duplicate-position protection correctly rejects the Library/Hill and `home_long` fixture inserts. The latter produces a normal Home screenshot, not the intended long-name state. Counting a named file without checking its actual content creates false coverage.
5. **Historical verification does not establish current owner acceptance.** The [completion report](../CONCEPT_B_COMPLETION_100_2026_10_24.md) records a bounded structural implementation and explicitly preserves the final owner gate. The [skill behavior validation](../../audit/CULMINA_DESIGN_SKILLS_BEHAVIOR_VALIDATION_2026_10_24.md) tests discovery/reasoning; its context-loading failures do not establish a pixel defect or justify rewriting all five skills. The [geo receipt](../qa/GEO_DATE_FEEDBACK_2026_10_24.md) also demonstrates why hot reload needs source verification. Keep these boundaries explicit when applying the existing workflow.

The remedy is a small caller-aware package plus state-specific review, using existing infrastructure. No new dependency, design skill, automated redesign pipeline or competing design system is proposed.
